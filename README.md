## 我们的研究聚焦方向？
- 代谢功能障碍相关脂肪性肝病，即MASLD（旧称NAFLD，非酒精脂肪性肝病），已经成为了引起肝硬化和肝细胞癌等终末期肝病增长最快的慢性病类型之一
- 寻找在MASLD人群的肝脏糖脂代谢通路中具有潜在重要功能但尚未被深入研究的基因
- 在细胞水平初步验证其对肝脏细胞脂质沉积的调控作用
- 拓宽对MASLD发病分子机制的认识，为后续潜在靶点开发提供初步理论依据和实验线索。
***
## 路径
1. 学习GEO数据库使用方法
2. 在数据库中筛选糖脂代谢相关表达数据
3. 找出在此前研究中被忽略的相关基因
4. 应用机器学习算法进行差异分析，确认相关性
5. 湿实验启动
